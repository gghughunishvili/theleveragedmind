Privacy Policy

Last updated: September 29, 2026

Who we are

The Leveraged Mind ("we") publishes educational content on Instagram and TikTok. The Leveraged Mind Publisher is a first-party software tool we operate to create and publish content to our own social media accounts.

What data the Publisher accesses

The Publisher connects only to social media accounts owned by us, using the platforms' official APIs (Meta Instagram API, TikTok Content Posting API and Login Kit). Through these it accesses: our own account profile (username, display name, avatar), the content we publish, and aggregate performance metrics of our own posts (reach, likes, comments, saves, shares). It does not access, collect or store personal data of followers, viewers or commenters beyond what the platforms display publicly.

Website visitors

This website is a static site hosted on GitHub Pages. We do not set cookies, run analytics, or collect personal information from visitors. GitHub may log standard server data (such as IP address) under its own privacy statement.

How data is stored and protected

API access tokens are stored encrypted-at-rest on a private machine under our control and are never shared with third parties. Content and performance metrics are kept in local logs used solely to improve our own publishing.

Data sharing

We do not sell, rent or share any data with third parties. Data is sent only to the platform we publish to (Meta or TikTok) and to our media host (Cloudinary) for the purpose of publishing our own content.

Data retention and deletion

Access tokens can be revoked at any time from the respective platform's settings. Local logs are retained for up to 12 months. To request deletion of any data, email giorgijr10@gmail.com.

Children

Our content and tools are not directed at anyone under 18.

Changes

We may update this policy; the "Last updated" date will change accordingly.
